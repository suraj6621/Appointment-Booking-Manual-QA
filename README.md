# Manual QA Project — Appointment Booking Web Application

## Overview
A beginner portfolio project documenting manual testing of the public Easy!Appointments demo.

**Application:** https://demo.easyappointments.org/

## What Was Tested
- Service and provider selection
- Appointment date and time selection
- Default date/time behavior
- Required-field validation
- Invalid email and phone validation
- Confirmation summary verification
- Final booking confirmation

## Project Deliverables
- `Test-Plan.md` — Scope, approach, environment, and limitations
- `Test-Cases-and-Execution.xlsx` — Test cases, expected and actual results, status, and notes
- `Bug-Reports.xlsx` — Bug report template; no confirmed defects identified so far
- `Test-Execution-Summary.md` — Test execution results and summary
- `Evidence/` — Screenshots captured during testing

## Current Status
The end-to-end appointment booking flow and several negative validation scenarios have been tested. Some test cases remain **Not Run** or **Partially Verified**.

No confirmed product defects have been identified so far.

## How to Review
Open the Excel workbook and filter by status to review completed tests and identify cases pending further testing.

## Test Data and Privacy
Only fictional test details were used. This project tests a public demo installation, not a production application. Screenshots and results reflect the testing performed.
